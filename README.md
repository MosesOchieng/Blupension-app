# Blupension - Blockchain-Based Pension Platform

A revolutionary pension platform leveraging blockchain technology to address the challenges of traditional pension systems in Kenya and beyond.

## Features

- 🔒 Automated Payments: Direct wallet deposits
- 📈 Growth-Oriented Investments: Bitcoin and stablecoin integration
- 📊 Real-Time Portfolio Tracking
- 🌐 Financial Inclusion: Accessible to banked and unbanked users
- 🤖 AI-Driven Investment Strategies
- 📱 User-Friendly Interface

## Investment Plans

1. **Aggressive Plan**
   - Higher allocation to high-growth assets
   - Maximum potential returns
   - Increased risk exposure

2. **Moderate Plan**
   - Balanced allocation between stablecoins and growth assets
   - Steady growth
   - Moderate risk

3. **Conservative Plan**
   - Predominantly stablecoin investments
   - Capital preservation focus
   - Minimal risk

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- MetaMask or similar Web3 wallet

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/blupension-app.git
cd blupension-app
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open [http://localhost:5173](http://localhost:5173) in your browser
